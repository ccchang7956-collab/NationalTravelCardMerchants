# 操作通知

2026-10-07 已部署至正式站。通知只出現在操作結果或需要使用者處理的問題；FAQ、關於、縣市與商家資訊頁正常開啟時不跳通知。

- 首頁：定位成功／失敗、無法生效的距離篩選；搜尋失敗後重試成功仍會通知，首訪資料失敗也會提示。
- 地圖：補上定位失敗、篩選定位失敗與載入更多失敗。查詢成功／空結果的既有回饋保留。
- 雷達：附近及手動搜尋成功、沒有結果、定位權限拒絕、不支援定位、離線或 API 失敗。過期與取消的雷達請求不發通知。
- 地址自動完成與行業分類背景載入保留欄位提示，避免打字或背景請求不斷跳通知。

通知最多同時三則，完全相同且尚未關閉的通知會去重。成功／提醒停留 4 秒，錯誤停留 8 秒；滑鼠及鍵盤焦點停留時暫停倒數，離開後繼續。手機顯示於上方，桌機於底部，支援安全區域；錯誤使用 alert，其餘使用 status，不自動搶焦點。可手動關閉，既有 inline error 不因通知關閉而消失。

通知 API 使用 `toast.success`、`toast.info`、`toast.error`；自訂輸入使用 `toast.show`。重構後全專案 ESLint 也通過，先前 Toast 的函式屬性賦值錯誤已修正。

驗證：23 組 Jest／144 個測試、typecheck、完整 ESLint、production build 通過。`e2e/toast.spec.ts` 使用隔離 Chromium 對正式站完成桌機定位拒絕／手動搜尋／空結果及手機 API 失敗／重試／上方通知位置驗收（2 個測試通過）。API 回應與 GPS 在測試瀏覽器中模擬，沒有修改正式商家資料。

一般驗收：`SMOKE_SITE_URL=https://ntc.shibaalin.com npm run test:e2e -- toast.spec.ts`。已有隔離 Chromium 時可指定 `SMOKE_CDP_URL` 連線。部署使用 `./deploy.sh`，部署後 4 個服務皆 healthy。
