## 一、檔案概覽

此 PDF 為「國民旅遊卡」特約商店的完整清冊，記錄全台可使用國民旅遊卡消費的店家資訊。由 **JasperReports Library 6.17.0** 產出，A4 橫置版面，每頁列出數十筆商家資料。

## 二、頁面結構

### 第 1 頁（封面）

```
國民旅遊卡特約商店清冊
檔案日期：YYYY/MM/DD
```

封面僅含標題與日期，**不含商家資料**，解析時應從第 2 頁開始。

### 第 2 頁起（資料頁）

每頁頂端固定有一列**表頭**，接著是商家資料：

```
特店名稱　　特店地址　　郵遞區號　　統一編號　　特店網頁位址
```

---

## 三、每筆資料的欄位說明

每筆商家資料佔 **4 行**（有網址則為 5 行），依序如下：

| 行次 | 欄位 | 說明 | 範例 |
|------|------|------|------|
| 第 1 行 | **特店名稱** | 商家名稱，可能含全形英文或中英混合 | `CHIC CHIC GIRL古亭店` |
| 第 2 行 | **特店地址** | 完整地址，含縣市區路號樓層 | `臺北市中正區羅斯福路2段198號` |
| 第 3 行 | **郵遞區號** | 3～6 位純數字 | `100` |
| 第 4 行 | **統一編號** | 恰好 8 位數字，為必填欄位 | `38560684` |
| 第 5 行 | **特店網頁位址** | 選填，並非每間商家都有 | `www.example.com.tw` |

## 四、注意事項與常見例外

### 4-1　表頭會在每頁重複出現

每頁第一行永遠是 `特店名稱`，接著 `特店地址`、`郵遞區號`、`統一編號`、`特店網頁位址`，**解析時必須跳過這 5 行**。

### 4-2　店名與地址偶爾合併成同一行

JasperReports 排版問題，部分店名過長時會與地址被合併成一行，中間以**多個全形空白（`　`）分隔**：

```
大集合精品鞋坊　　　　　　台北市中正區羅斯福路4段28號
```

解析時需以 2 個以上的空白或全形空白（`\u3000`）作為切割依據。

### 4-3　全形英數字

PDF 中的英文字母與數字多為**全形**（如 `Ａ`、`１`），建議匯入資料庫前統一做 **NFKC Unicode 正規化**，轉為半形方便搜尋。

```python
import unicodedata
normalized = unicodedata.normalize("NFKC", text)
```

### 4-4　字型缺陷，部分工具無法解析

此 PDF 字型嵌入不完整（`Adobe-CNS1` mapping 缺失），以下工具**無法正確讀取中文**：

- ❌ `pdftotext`（poppler）
- ❌ `pypdf`

請改用：

- ✅ **PyMuPDF（`fitz`）** — 推薦，中文完整，速度快

```bash
pip install pymupdf
```

### 4-5　統一編號為資料完整性的判斷依據

統一編號（8 位數字）是每筆記錄的**必填欄位**。若解析到某行符合此格式，即代表當前記錄完整，可安全寫入資料庫。

## 五、資料庫欄位建議

| 欄位名稱 | 型別 | 說明 |
|----------|------|------|
| `id` | INTEGER PK | 自動流水號 |
| `name` | TEXT | 特店名稱 |
| `address` | TEXT | 特店地址 |
| `zip_code` | TEXT | 郵遞區號 |
| `tax_id` | TEXT | 統一編號 |
| `website` | TEXT | 特店網頁位址（可為空） |

建議在 `name`、`zip_code`、`tax_id` 建立索引，以加速查詢。

## 六、快速解析流程圖

```
開啟 PDF（PyMuPDF）
    │
    ├─ 第 0 頁（封面）→ 跳過
    │
    └─ 第 1 頁起，逐頁處理
            │
            ├─ 遇到表頭行（特店名稱等 5 行）→ 跳過
            │
            └─ 解析資料行：
                    名稱（含合併地址判斷）
                    ↓
                    地址
                    ↓
                    郵遞區號（3~6 位數字）
                    ↓
                    統一編號（8 位數字）← 必填，作為記錄完整判斷
                    ↓
                    網址（可選）
                    ↓
                    寫入 SQLite
```
